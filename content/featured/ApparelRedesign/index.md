## Overview

A redesign concept for an apparel store that had grown section by section until the homepage no longer had a clear message.

## The Challenge

Too many competing banners, inconsistent typography and a menu with more than twenty entries made the store hard to scan.

## Strategy

Reduce the homepage to a small number of purposeful sections, consolidate the menu, and standardise every card and button.

## Design Approach

A bold editorial grid with high-contrast type, one accent colour, and a consistent component library across templates.

## Development

Rebuilt homepage sections as configurable blocks so campaigns can be swapped without adding new one-off sections.

## Optimization

Size guidance, returns information and stock signals were moved above the fold on mobile product pages.

## Key Features

- Consolidated navigation menu
- Configurable campaign sections
- Standardised product cards and buttons
- Mobile-first product page layout

## Outcomes

- Improved visual consistency across the store
- Cleaner navigation and reduced menu depth
- Better mobile experience on key templates
